### Результати 5 тестів `parseValue()`
1. `parseValue("5,5")` → `{ number: 5.5 }` (коректне дробове число з комою).
2. `parseValue("")` → `{ error: "Введіть значення." }` (порожній рядок відсіяно до `Number()`).
3. `parseValue("abc")` → `{ error: "Введіть коректне число, наприклад 5,5." }` (нечисловий текст дає `NaN`, перевіряється через `Number.isFinite()`).
4. `parseValue("-3")` → `{ error: "Значення не може бути від'ємним." }` (від’ємне число відхилено).
5. `parseValue(" 12 ")` → `{ number: 12 }` (зайві пробіли по краях обрізано через `.trim()`).

### Роль `.slice()` перед `.sort()`
Метод `.sort()` змінює (мутує) вихідний масив на місці. Виклик `.slice()` перед `.sort()` створює поверхневу копію масиву `catalog`, щоб початковий порядок елементів не змінювався й кнопка **«Усі»** завжди повертала вихідний невідсортований список.
